# Yet Another Dictator — Android

Native Android companion to the [macOS Dictator app](https://github.com/captainDuckay/yet-another-dictator)
and the [iOS app](https://github.com/captains-chest/yet-another-dictator-ios). Work in progress:
this commit is the scaffold (Gradle, the `core` port of DictationCore and its tests, CI).
